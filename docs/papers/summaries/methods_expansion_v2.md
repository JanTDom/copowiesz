# Lektura metod — rozszerzenie v2

Data: 2026-10-07. Zastosowano paper-reading: najpierw rekord i abstrakt, następnie wybrane sekcje metod/wyników dla kluczowych źródeł. Nie wykonano pełnych lektur wszystkich publikacji ani przeglądu systematycznego. Wszystkie odczyty były bezpłatne; brak Scite, triali i zakupów.

Korekty i ograniczenia:

- VIDOPET: [korekta wydawcy 2019](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0224199) dotyczy dostępności danych. Nie przeprowadzono pełnego audytu retrakcji.
- Rekordy z abstraktem pozostają ograniczone do abstraktu; brak dokładnej liczebności jest zapisany zamiast uzupełnienia domysłem.
- CatFLW i DogFLW: preprinty, brak pobrania danych lub uzyskanych praw treningowych.
- WOAH: odczytano oznaczoną wersję PDF 2024, bez potwierdzenia aktualności wszystkich standardów.
- NIST: metodologia generatywnej AI, bez biologicznych dowodów o psie i kocie.
- ARRIVE: ogólny zakres żywych zwierząt, bez walidacji domowego produktu.

Przyjęte decyzje projektu są wyraźnie oddzielone w kartach jako `project_recommendation`. Autorski etogram stosuje `project_operational_definition`; bibliografia nie oznacza źródłowego pochodzenia jego definicji. Pozwala to odróżnić to, co opublikowano, od nowej reguły działania i nowego kodu wymagających oceny.

Nie skopiowano pozycji skal, materiałów instrukcji, pełnych tekstów, obrazów ani nagrań. Dłuższe streszczenia należy tworzyć z kontrolą łącznego limitu na źródło; bieżące notatki celowo pozostają krótkie.
